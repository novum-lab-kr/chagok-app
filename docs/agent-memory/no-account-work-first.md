계정(Apple Developer Program, Google Cloud OAuth)이 준비되기 전에는 개발 빌드 전환을 포함해 계정이 걸린 단계를 다음 할 일로 제안하지 않는다. 지금 할 수 있는 개발(Expo Go, Storybook, 개발용 이메일 로그인)을 먼저 고른다.

**Why:** 2026-10-01 "커밋하면 바로 개발 빌드 전환"이라고 제안했다가 사용자가 짜증 냄 — "계정 아직 준비 안됐다니깐, 준비 전에 할 수 있는 개발들을 먼저 한다니까". HANDOFF도 순서를 "준비물이 갖춰지면 개발 빌드 전환 → 서버 → 로그인"으로 적어 둠. 시뮬레이터로 계정 없이 된다는 기술적 사실이 있어도 사용자 순서가 우선.

**How to apply:** 다음 작업을 고를 때 HANDOFF 「Expo Go로 할 수 있는 것」과 앱 연결 남은 것부터 본다. 계정·개발 빌드가 필요한 일은 "준비물 뒤"로 묶어 따로 적는다.
