새싹이(`sprout`)는 기본 스티커 6종 중 하나이고, 앱의 메인 캐릭터·대표 이미지가 아니다. 앱 아이콘·스플래시·브랜드 시안에 새싹을 대표로 내세우지 않는다. 메인 캐릭터나 브랜드 방향은 문서에 정해져 있지 않으니 추측하지 말고 사용자에게 묻는다.

**Why:** 2026-10-03 아이콘·스플래시 시안에서 기본 스티커라는 이유만으로 새싹을 대표로 썼다가, 사용자가 "메인 캐릭터가 새싹이 아닌데 왜 자꾸 새싹을 미냐"고 했다. 시안 3개씩이 모두 "별로"였다.

**How to apply:** 브랜드 시안 전에 대표 이미지(캐릭터·심볼)를 먼저 확인한다. [[proposals-as-artifact]] 형식으로 보여준다.
