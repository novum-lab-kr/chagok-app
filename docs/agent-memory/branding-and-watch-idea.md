- 2026-10-03 캐릭터가 없어 브랜딩부터 했다(새싹이는 대표가 아님 [[sprout-not-mascot]]). 2026-10-04 「이고지고」(가칭) 확정: 책 모양 판 세 장, 기본 팔 없음(점 팔 1·2는 변형), 표정 10가지(기쁨 미소·활짝·신남), 졸림 z+점, 아이콘 민트 전신. 단일 출처는 PRD 4.11과 `docs/design/character/`(데이터 JSON·그리기 코드).
- 남은 것: 캐릭터 이름, 스플래시(후보: 판이 쌓이고 글자가 써지는 애니메이션), 표정 쓰임새(초안), 앱 설정 배치.
- 워치 아이디어(키우기 + 빠른 붙이기)는 구체화 전. 키우기는 PRD 2절 "캐릭터 돌보기 게임이 아니다"와 부딪치므로 원칙부터 묻는다.

**Why:** 브랜드가 정해지기 전 아이콘 시안이 모두 반려됐고, 캐릭터는 여러 차례 시안으로 좁혀 확정했다.
**How to apply:** 캐릭터를 그리거나 앱에 넣을 때 `docs/design/character/README.md`의 그리기 규칙(z는 5×5 등)을 따른다. 이름·스플래시는 정하기 전에 임의로 넣지 않는다.
