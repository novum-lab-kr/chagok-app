- 2026-10-03 캐릭터가 없어 브랜딩부터 했다(새싹이는 대표가 아님 [[sprout-not-mascot]]). 2026-10-04 확정, 이름 「차곡이」(가칭이던 「이고지고」에서): 책 모양 판 세 장, 기본 팔 없음(점 팔 1·2는 변형), 표정 10가지(기쁨 미소·활짝·신남), 졸림 z+점, 아이콘 민트 전신. 단일 출처는 PRD 4.11과 `docs/design/character/`(데이터 JSON·그리기 코드).
- 2026-10-04 확정: 표정 쓰임새(Storybook `Brand / Mascot` 그대로), Android 아이콘 A1, 스플래시 S2-B(윤곽선 → 색 채우기 → 좌우로 판 받기 → 커서 글자). 남은 것: 앱 설정 배치.
- 워치 (2026-10-04 사용자와 논의, 2026-10-08 PRD 2절·11절·확정 이력에 반영): 목적은 게임이 아니라 스티커를 꾸준히 붙이게 돕고 앱을 계속 쓰게 하는 것, 워치는 그걸 간편하게 하는 수단. 성장 방식 = **쌓인 만큼 자라기**(누적 스티커로 성장, 안 붙여도 줄거나 시들지 않음, 연속일수·재촉 없음) → PRD 2절 "성장 보상에 쓰지 않는다"만 바꾼다. 같은 레포(`targets/watch/` apple-targets, `wear/` 독립 Gradle), 폰이 계산하고 워치는 보여 주기·붙이기 요청만. RN은 watchOS 불가, Wear OS 비추천. **플랫폼 순서는 미정**(Apple Watch 먼저를 추천).

**Why:** 브랜드가 정해지기 전 아이콘 시안이 모두 반려됐고, 캐릭터는 여러 차례 시안으로 좁혀 확정했다.
**How to apply:** 캐릭터를 그리거나 앱에 넣을 때 `docs/design/character/README.md`의 그리기 규칙(z는 5×5 등)을 따른다. 확정 전 브랜드 요소를 임의로 넣지 않는다.
