# 출시 문서

스토어 출시에 필요한 문서를 이 폴더에 모은다. 한 사실은 한 문서에만 적고, 다른 문서는 링크로 가리킨다. 지금 진행 상황과 인계는 [HANDOFF](../HANDOFF.md)에 있다.

| 문서 | 무엇 | 언제 읽나 |
| --- | --- | --- |
| [1.0.1.md](1.0.1.md) | 1.0.1 출시 순서. 심사 시점별 처리, 운영 DB 반영 순서 | 1.0.1을 합치거나 내보낼 때 |
| [checklist.md](checklist.md) | 출시 전 최종 점검 목록 | 스토어에 내기 직전 |
| [decisions.md](decisions.md) | 식별자, 계정, 가격, 광고, 출시 순서 같은 확정 결정과 열린 결정 | 출시 관련 값을 정하거나 근거를 찾을 때 |
| [versioning.md](versioning.md) | 버전과 빌드 번호 규칙, 빌드 올리는 법, EAS 환경 변수 | 빌드를 만들 때 |
| [app-store-submission.md](app-store-submission.md) | App Store 제출 문안(심사 메모, 상품 메모, 설명)과 원문 근거 | App Store Connect에 글을 넣을 때 |
| [store-privacy.md](store-privacy.md) | Privacy Manifest, 개인정보 라벨, Play 데이터 보안, 연령 등급 답안 | 수집 정보나 SDK가 바뀔 때 |
| [legal-review.md](legal-review.md) | 약관과 처리방침이 기대는 법령, 출시 때마다 하는 법령 검토 | 출시와 업데이트 때마다 |

운영 서버는 [운영](../OPERATIONS.md)에 있다.
