## Goal

사용자가 스스로 정의한 목표에 대해 **스티커를 직접 붙여** 진행을 기록하고, 원할 때 그 스티커에 **사진/메모 기록을 선택적으로 첨부**하며, 쌓인 판을 열어보는 것만으로 **성취감을 얻는** iOS/Android 앱.

핵심 가치는 **"나중에 모아서 볼 때의 성취감"**이며, 판정·평가·타인 개입은 명시적으로 배제한다.

## Constraints

- 플랫폼: **Expo (React Native)**, iOS + Android 동시 출시
- 데이터: **계정 + 클라우드 동기화** (기기 교체 시 데이터 보존이 제품 가치의 전제조건)
- 판 타입 2종: `calendar`(날짜 그리드) / `tally`(N칸 순차). **데이터 모델은 공통, 렌더링만 분기**
- 스티커는 사용자가 **직접 붙이고 뗄 수 있다** (취소 자유)
- 기록(사진/메모)은 **선택 사항**이며 스티커에 종속된 릴레이션
- 목표는 사용자가 자유롭게 정의 (도메인 제한 없음)
- 출시 전략: 가볍게 빠르게 출시 → 사용자 확보 후 고도화

## Non-Goals

- **타인의 판정/인정** — "검사받는 느낌"을 주므로 명시적으로 배제
- **AI/시스템의 등급 판정** — 임의 목표에 대한 자동 판정은 성립 불가로 판명 (Round 2~3)
- **취소 불가 / 기록 잠금** — 사용자 자유 수정 허용
- **통계·잔디밭·연속일수** — 기존 습관 앱과 차별성 없고 연속 끊김이 이탈 요인
- **별도 회고/아카이브 화면** — 판 자체가 회고 (Round 6)
- **보상 시스템** — MVP 범위 밖 (보류)

## Acceptance Criteria

- [ ] 목표를 생성할 때 이름과 판 타입(`calendar` | `tally`)을 지정할 수 있다
- [ ] `tally` 타입 목표는 총 칸 수를 지정할 수 있다
- [ ] 목표 상세 화면에서 스티커를 붙일 수 있고, 붙인 스티커를 뗄 수 있다
- [ ] `calendar` 판은 날짜 그리드에 스티커를 배치하고, 안 붙인 날은 빈칸으로 보인다
- [ ] `tally` 판은 붙인 순서대로 칸을 채우고 `현재/전체` 진행을 표시한다
- [ ] 스티커를 붙일 때 사진 또는 메모를 첨부할 수 있고, **첨부하지 않아도 정상 동작한다**
- [ ] 기록이 첨부된 스티커는 판에서 시각적으로 구분되며, 탭하면 기록을 볼 수 있다
- [ ] 앱 재설치 또는 다른 기기 로그인 후에도 모든 목표·스티커·기록이 복원된다
- [ ] 목표가 하나도 없는 최초 실행 상태에서도 화면이 비어 보이지 않고 다음 행동이 분명하다
- [ ] 스티커를 붙이는 순간 촉각/시각 피드백이 있다 (햅틱 + 모션)
