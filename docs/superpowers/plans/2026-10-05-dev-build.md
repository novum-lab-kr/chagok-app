# 개발 빌드 전환 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expo Go 대신 개발 빌드(`expo-dev-client`)로 iOS 시뮬레이터·Android 에뮬레이터에서 앱을 돌리고, EAS 프로젝트를 Expo 조직 아래에 연결해 둔다. Apple 승인이 나면 서명·TestFlight로 바로 넘어갈 수 있는 상태가 목표다.

**Architecture:** 네이티브 폴더(`ios/`·`android/`)는 CNG로 매번 만들고 커밋하지 않는다(HANDOFF 「준비물이 필요한 것」). 설정은 `app.json`·`eas.json`에만 둔다. 앱 코드는 바꾸지 않는다 — 쓰는 네이티브 모듈이 모두 `package.json`에 이미 있다(2026-10-05 import 대조).

**Tech Stack:** Expo 57, `expo-dev-client`, `expo-system-ui`, `npx expo run:ios|android`, EAS CLI(`npx eas-cli`), Xcode 27, JDK 17(Zulu).

**Spec:** [HANDOFF](../../HANDOFF.md) 「계정이 생긴 뒤」·「준비물이 필요한 것」, [버전 규칙](../../RELEASE-VERSIONING.md) 「처음 한 번」, Expo 문서 [Create a development build](https://docs.expo.dev/develop/development-builds/create-a-build/)·[SystemUI](https://docs.expo.dev/versions/v57.0.0/sdk/system-ui/)

## Global Constraints

- Expo 57. API는 https://docs.expo.dev/versions/v57.0.0/ 에서 확인한다.
- `package.json` `overrides: { "react-dom": "19.2.3" }` 유지. 설치 전 `package.json`·`package-lock.json` 백업, 설치 후 `npm ls react-dom --all`이 `19.2.3` 하나만.
- `ios/`·`android/` 커밋 금지(`.gitignore`).
- `app.json`에 `ios.buildNumber`·`android.versionCode`를 넣지 않는다(EAS 원격 관리 — 버전 규칙).
- 번들 ID `com.novum.chagok`는 바꾸지 않는다.
- 앱 코드·디자인 시스템 값은 바꾸지 않는다. 바꿔야 할 일이 생기면 멈추고 묻는다.
- 커밋은 **사용자가 개발 빌드를 직접 돌려 본 뒤**에 한다(메모리 규칙). 브랜치 `feat/dev-build`.
- 개발 서버(Metro)는 사용자가 터미널에서 돌린다(DEV-SETUP). 에이전트는 빌드 명령만 실행한다.

## Review Focus

1. **Expo Go 경로가 사라지지 않는지** — `expo-dev-client`를 넣으면 `npx expo start`가 개발 빌드를 기본으로 연다. 실기기는 아직 Expo Go로 보므로 `npx expo start --go`가 계속 되어야 한다 → Task 2 Step 6에서 확인.
2. **다크 모드가 시스템을 따르는지** — `userInterfaceStyle: automatic`은 개발 빌드에서 `expo-system-ui` 없이는 Android에서 적용되지 않는다 → Task 2·3에서 라이트/다크 전환 스크린샷.
3. **`.env.local`(서버 주소·개발 계정)이 개발 빌드에서도 읽히는지** — 앱 설정 → 개발 → 서버 동기화 화면에서 로그인 → Task 2·3 확인 목록.
4. **기존 기록이 개발 빌드로 넘어오지 않는다** — Expo Go와 개발 빌드는 다른 앱이라 SQLite가 따로다. 버그가 아니므로 문서에 적는다 → Task 5.
5. **아이콘·스플래시가 OS에서 제대로 보이는지** — 지금까지 Expo Go라 OS 그림을 본 적이 없다(HANDOFF 「확정」 줄) → Task 2·3 스크린샷.
