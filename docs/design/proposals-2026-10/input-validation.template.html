입력 글자 수와 안내 문구

목표 이름과 기록 메모에 글자 수 제한을 두고, 입력칸 바로 아래에 안내 문구를 보여 줍니다. 화면은 지금 앱의 화면 컴포넌트로 그렸고, 문구 줄은 기존 「칸 수」 오류 문구와 같은 작은 글자입니다. 안마다 다른 것은 글자 수(17/20)를 언제 보여 주느냐 하나입니다.

이미 정한 것 (2026-10-08)
  • 목표 이름 20자, 메모 500자. 띄어쓰기도 한 글자로 센다.
  • 최대 글자 수가 되면 더 입력되지 않는다.
  • 한도에 닿으면 입력칸 아래에 「20자까지 입력할 수 있어요.」(메모는 500자)를 보여 준다.
  • 이름이 비었거나 띄어쓰기만 있으면 「목표 이름을 입력해주세요.」를 보여 주고 [만들기]·[저장하기]는 지금처럼 흐리게 둔다.
함께 정해지는 것 (다르게 하고 싶으면 메모에 적어 주세요)
  • 「목표 이름을 입력해주세요.」는 새 목표 화면을 처음 열었을 때는 보이지 않는다. 이름을 썼다가 지웠거나, 입력칸을 눌렀다가 비운 채 나왔을 때 보인다.
  • 메모는 비워 둬도 되는 칸이라 「비었어요」 문구는 두지 않는다. 띄어쓰기만 적은 메모는 빈 메모로 저장한다.
  • 이름 앞뒤 띄어쓰기는 저장할 때 지운다(지금과 같다).
  • 목표 설정 화면의 이름 칸도 새 목표와 똑같이 동작한다.
  • 20자 이름은 입력칸에 한 줄로 딱 맞고, 홈 카드에서는 두 줄로 보인다(아래 「지금」 줄 마지막 그림).
