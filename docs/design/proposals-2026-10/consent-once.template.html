가입과 로그인 줄이기

차곡차곡 첫 실행과 계정 연결 흐름의 두 번째 시안이에요. 비슷한 앱들이 가입과 로그인을 어떻게 받는지 살펴보고, 지금보다 누르는 횟수를 줄인 세 안을 만들었어요. 캡처는 앱의 실제 컴포넌트로 그렸어요.

지금 흐름이 불편한 이유

  • 로그인까지 다섯 번 눌러요. 시작 화면 [계속], 체크 두 개, Apple 버튼, Apple 창 확인.
  • 다시 로그인해도 같아요. 로그아웃하면 기기 기록이 지워져서 두 체크를 또 받아요.
  • 14세 미만이 시작 화면을 맴돌아요. 안내 뒤 [확인]을 누르면 같은 시작 화면으로 돌아와요.

비슷한 앱은 어떻게 하나

  • 버튼 아래 안내 한 줄. Notion, Duolingo, Day One 같은 앱은 로그인 버튼만 두고, 아래에 "계속하면 약관에 동의한 것으로 봐요"를 적어요. 체크가 없어요.
  • 새 계정만 동의 받기. 국내 앱은 로그인 먼저 하고, 처음 가입한 사람에게만 "전체 동의" 시트를 띄우는 경우가 많아요. 카카오싱크 간편가입은 아예 카카오 로그인 창 안에서 약관 동의를 같이 받고, 이미 가입한 사람에게는 다시 보이지 않아요.
  • 먼저 써 보게 하기. Duolingo는 가입 화면을 몇 단계 뒤로 미뤘더니 매일 쓰는 사람이 약 20% 늘었다고 알려져 있어요(회사 인터뷰를 옮긴 글 기준). 기록 앱 Daylio처럼 계정 없이 시작하고 백업만 나중에 켜는 앱도 많아요.
  • 법이 바뀐 점. 2023년 9월 개인정보 보호법 개정으로, 서비스 계약을 이행하는 데 꼭 필요한 정보는 따로 동의를 받지 않아도 돼요. 그래서 "개인정보 처리방침 동의" 체크는 필요 없고 안내로 충분해요. 다만 만 14세 미만은 여전히 보호자 동의가 필요해서 나이 확인은 남겨요.
  • Apple 심사. Apple로 로그인한 뒤 쓸데없는 단계나 추가 정보를 요구하면 심사에서 지적받은 사례가 있어요. 단계가 짧을수록 좋아요.

출처: 개인정보보호위원회 필수동의 관행 개선 기사(newsseoul.co.kr), 카카오 개발자 문서 카카오싱크(developers.kakao.com/docs/latest/ko/kakaosync), Duolingo 가입 지연 실험 정리(taplytics.com/blog/duolingo-ab-test-onboarding), Day One Sign in with Apple(dayoneapp.com). Notion, Duolingo, Day One의 버튼 아래 문구와 Daylio의 계정 방식은 이번 조사에서 원문을 확인하지 못했어요.

이미 정한 것 (모든 안에 같이 들어가요)

  • 약관 동의 기록은 처음 가입할 때만 남겨요. 다시 로그인할 때는 묻지 않아요.
  • "만 14세 미만이에요"를 누르면 안내 뒤 이 기기 모드로 바로 시작해요. 시작 화면으로 돌아가지 않아요.
  • 14세 미만이라고 답한 기기는 광고를 아동용으로 요청하고, 광고 등급 상한을 G(전체 이용가)로 붙여요.
  • 로그인 버튼은 지금처럼 Apple 하나예요. 카카오와 Google을 붙이면 같은 줄에 동그라미가 늘어나요.
