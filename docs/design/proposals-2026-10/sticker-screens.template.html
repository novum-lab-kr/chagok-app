컬러 스티커를 화면에 넣는 설계의 최종 흐름입니다(2026-10-07 확정). 정한 것: 모두 컬러(A1) · 가림막 카드(L5, 「눌러서 미리 보기」) · 묶음 10종, 가진 묶음은 고른 묶음만 펼침(Q3-3) · 잠긴 묶음 → 묶음 화면(C2), 산 뒤 자동으로 고르기로 · 앱 설정 「구매」 블럭(광고 제거 + 구매 복원) · 보상은 붙인 날 7·14·이후 30일마다 3일 체험 · 체험이 끝나면 다음에 붙일 때 안내. 미룬 것: 스티커 그림 품질(품질 점검), 출시 세 주제. 장면마다 메모를 남길 수 있습니다.

그린 방법. 앱 화면은 실제 디자인 시스템 컴포넌트(머리글, 패널, 버튼, 필터, 판 칸, 다이얼로그, 설정 줄)로 조합해 Storybook에서 iPhone 16 Pro 크기(390pt)로 렌더한 캡처입니다. 안은 지금 화면 구조 안에서만 바꿨고, 디자인 시스템에 없는 새 요소(자물쇠·재생 표시 아이콘, 보상 안내 상자, 아래 고정 줄 등)는 안마다 밝혔습니다. 회색 광고 배너와 App Store 결제창은 앱 밖에서 오는 것이라 예시로만 넣었습니다.

결제·광고가 닿는 곳

  • 정함 광고는 홈(내 목표·완성한 판) 맨 아래 고정 배너뿐입니다. 판·스티커 고르기·기록·앱 설정에는 없습니다.
  • 정함 묶음 2,200원, 광고 제거 5,500원. 따로 파는 상품이라 묶음을 사도 광고는 그대로입니다.
  • 정함 잠긴 묶음의 스티커도 이미 붙인 칸에서는 그대로 보입니다. 새로 고를 때만 막습니다.
  • 없음 스티커를 고르는 곳은 새 목표와 목표 설정의 「기본 스티커」 하나입니다. 지금은 전체/친구/모양/사물 필터에 흑백 6종이 있고, 묶음이나 잠김 개념이 없습니다.
  • 없음 묶음을 사는 화면, 광고 제거를 사는 곳, [구매 복원]이 없습니다. App Store 심사는 [구매 복원]을 요구합니다.
  • 없음 판에 붙일 때 종류를 고르지 않습니다(한 판 = 한 스티커). 그래서 묶음을 사도 바로 쓰는 곳은 기본 스티커를 바꾸는 순간입니다.

지금 흐름에서 묶음이 들어갈 자리

  • 홈 → [+] 새 목표 → 기본 스티커 → 만들기
  • 판 상세 → 톱니바퀴 → 목표 설정 → 기본 스티커 → 저장
  • 홈 → 톱니바퀴 → 앱 설정 → (새 구역) 스티커·광고
  • 잠긴 묶음을 누르면 → 묶음 열기(구매) → 고르던 화면으로 돌아와 바로 고름

흐름도(Storybook Flows/앱 전체)에는 고른 안에 맞춰 화면과 이동을 더합니다.

차곡차곡에 비춰 본 것

  • 국내 사용자는 "세트 하나 2,000~2,500원"에 익숙합니다. 카카오 이모티콘이 기준점이라 묶음 2,200원은 낯설지 않은 가격입니다. 다만 E3는 6종이라 이모티콘 한 세트보다 개수가 적어 보일 수 있습니다. 가격을 유지할지, 묶음 크기를 키울지 함께 보면 좋습니다.
  • 스토어 수수료 때문에 앱 안 가격이 웹보다 비쌉니다(카카오 2,500 vs 2,000원, 구독 6,900 vs 3,900원). 차곡차곡은 웹 결제가 없으니 스토어 가격표 하나만 씁니다.
  • 꾸미기 상품은 "화폐" 방식이 흔합니다(하루콩 클로버, LINE 코인). 화폐가 있으면 광고 보상·누적 보상을 같은 단위로 줄 수 있지만 화면과 정산이 복잡해집니다. 지금 설계(묶음을 직접 사고, 보상은 묶음 하나)가 더 단순합니다.
  • 해외 습관·기록 앱은 구독 중심(월 $5~10, 연 $36~70)이고 연간 할인과 무료 체험을 붙입니다. 나중에 구독(모든 묶음 + 광고 제거)을 낼 때 참고할 범위입니다.
  • 쓰면서 번 것으로 해금하는 방식(Forest의 코인)이 우리 누적 보상(③)과 같은 결입니다. 광고를 보면 정해진 시간만 해금하는 것도 흔한 보상형 광고 방식입니다(②).

모든 안 공통

  • 판 위 스티커 크기는 위 표를 따릅니다. 적립판 칸(84×64)은 그대로 두고 그림만 44 → 48로 키웁니다.
  • 잠긴 묶음은 자물쇠와 흐린 그림으로 보여 줍니다. 묶음을 열면 고르던 화면으로 돌아와 그 스티커가 골라진 상태가 됩니다.
  • 결제는 스토어 결제창(Apple·Google)이 띄웁니다. 앱은 그 앞뒤 화면만 그립니다. 결제 중에는 버튼에 로딩 점을 씁니다.
  • 문구는 사용자 쪽에서 씁니다: "묶음을 열었어요", "산 적이 있으면 다시 불러올 수 있어요".
  • 구독은 나중이라 이 시안에 넣지 않았습니다. 들어오면 같은 자리에 「모든 묶음 + 광고 제거」 줄이 하나 늘어납니다.
