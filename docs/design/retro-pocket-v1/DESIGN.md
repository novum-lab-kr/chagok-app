# Retro Pocket · 디자인 기준

**외형 기준은 [v6 홈](revisions/v6/screens/01-home.png)이며, 새싹·기본 스티커 영역은 [사용자 지정 원본](revisions/v6/references/sprout-and-label-source.png)을 따른다.**

`screen-preview` HTML 및 `review-set-01`은 사용자가 거절한 작업이다. 이를 재현 기준으로 사용하지 않는다. 토큰은 일관성을 위한 구현 자료이며, 기준 시안의 입체감·글씨 굵기·프레임을 평면화하거나 바꾸는 근거가 아니다.

이 파일에 흩어져 있던 이전 글씨·표면 제안은 단일 명세로 통합했다. 앱 내부 글씨 전체 도트, OS 상태바 기본 글씨, 필터 테두리 없음, 기본 스티커 라벨 유지가 현재 기준이다.

지정 시안은 외형 재현 기준이다. 색상·폰트·자산 형태를 시안마다 다시 추출하지 않는다. 앱 코드는 아직 이 토큰과 연결하지 않았다.
