# PRD 시안 공통 컴포넌트

2026-09-28 · [PRD 추가 화면 시안](../prd-additions-review/README.md)에 반복되거나 상태별 확인이 필요한 네 묶음을 Storybook 컴포넌트로 옮겼다. 기존 팔레트·프레임·토큰은 바꾸지 않았다.

| --- | --- | --- |
| ![프레임 안 사진 추가](사진-프레임-추가-320.png) | ![오른쪽 위 사진 삭제](사진-프레임-오른쪽-위-삭제-320.png) | ![사진 불러오기 실패](사진-프레임-불러오기-실패-320.png) |

`PhotoAttachment`의 `actionsInFrame`을 사용한다. 빈 상태는 추가 버튼만, 첨부 상태는 오른쪽 위 삭제 버튼만 표시한다. [메모와 함께 놓인 상태](사진-메모-빈-상태-320.png)도 확인할 수 있다.

| --- | --- | --- | --- |
| ![기록 표식 조건](기록-표식-모서리-사각형-320.png) | ![설정 이동 행](이동-행-320.png) | ![백업 대기 알림](짧은-알림-백업-대기-320.png) | ![복원 중 로딩](로딩-표시-복원-중-320.png) |

`GoalStickerCell`은 사진만·메모만·둘 다 기록이 있는 붙인 칸에 같은 B안 사각형을 표시한다. 기록이 없거나 빈칸이면 표시하지 않는다. `SettingRow`는 [값 표시](현재-값-320.png)·[긴 문구](긴-문구-320.png)·[비활성](비활성-320.png) 상태를 추가했다. `ShortNotice`는 [저장 완료](짧은-알림-저장-완료-320.png)·백업 대기·[저장 실패](짧은-알림-저장-실패-320.png) 문구를 같은 프레임으로 보여준다. 로딩 표시는 현재 시안대로 정적인 3개 점이다.

Storybook의 **Components / Screen Building Blocks**, **Stickers**, **Setting row**, **Feedback**에서 13개 스토리를 볼 수 있다. [검증 결과](verification.json)는 390px·320px 캡처 26장의 브라우저 오류·가로 넘침 상태를 기록한다. 재검사는 `node scripts/review-component-additions.mjs`로 실행한다. 이 컴포넌트는 시안에 사용했으며 앱의 백업·설정 흐름 연결은 별도 작업이다.
