# v3 · 전체 도트 타이포 + 첫 실행 튜토리얼

## 최신 결정

앱 내부 모든 텍스트를 한글 도트/비트맵 스타일로 통일한다. 제목뿐 아니라 버튼, 카테고리, 이름, 입력값, 사용자 메모, 날짜, 오류 메시지, 튜토리얼 문장에도 동일한 규칙을 적용한다.
휴대폰 OS 상태바(시계·배터리)는 사용자의 명시적 동의에 따라 기본 형태를 유지한다. 시스템 키보드·사진 선택기 등 OS UI는 앱 텍스트 범위 밖이다.
기존 문서의 ‘긴 안내·메모·입력은 고딕’ 기준은 이 결정으로 대체한다.

홈의 상시 안내문과 손 아이콘을 제거했다. 기본 스티커 바로가기는 작은 스티커와 화살표로 줄인다. 접근성 이름은 ‘기본 스티커 변경’으로 유지한다.
설정의 ‘이 목표에 붙일 스티커’, ‘이미 붙인 스티커는 그대로 남아요’ 같은 상시 가이드도 제거한다. 기존 스티커 보존 동작 자체는 유지한다.
필수 입력 라벨·오류 설명·삭제 확인까지 없애지는 않는다. 필요할 때 짧게 도트 글씨로 보여준다.

## 튜토리얼 흐름

첫 실행에만 실제 화면 모양을 이용한 **데모 미리보기**를 보여준다. 예시 목표·스티커는 실제 DB에 저장하지 않는다.
각 단계는 강조된 대상 1개, 제목 1개, 한 문장만 사용한다.

1. ‘목표 만들기’ / ‘＋를 눌러 목표를 만들어요’ / 다음
2. ‘스티커 고르기’ / ‘목표마다 스티커를 정해요’ / 다음
3. ‘빈칸에 톡!’ / ‘누르면 스티커가 붙어요’ / 시작하기

각 단계에서 ‘건너뛰기’를 제공한다. 완료·건너뛰기 후 표시 여부를 저장하고, 자동으로 반복하지 않는다.
종료하면 사용자의 실제 홈으로 이동한다. 목표가 없다면 설명 문단 없이 빈 판과 ‘새 목표’ 버튼을 보여준다.
재열람은 설정의 보조 항목 ‘사용법’으로 제공하는 것을 제안한다.
튜토리얼 전환은 버튼 기반이며 자동 타이핑이나 강제 대기 시간을 넣지 않는다.
스크린리더는 대화창을 먼저 읽고, 뒤의 예시 조작부에는 포커스가 가지 않게 한다.

## 스타일 적용 범위와 검토

이번 이미지 수정 범위는 홈·목표 설정과 튜토리얼이다. 기존 달력·새 목표·기록 이미지에는 이전 글씨·가이드가 남아 있으며 최신 규칙을 반영한 재렌더는 아직 하지 않았다.
향후 이 화면들도 전부 도트 글씨로 바꾸고, 긴 설명은 제거한다. 새 목표 화면은 ‘새 목표’ 제목과 필드 라벨만 남기고 큰 질문형 헤드라인을 삭제한다.
도트 가독성은 글꼴 교체 예외 대신 적절한 크기·행간·글자 확대·선명한 대비로 확보한다. 실제 폰트 파일은 아직 선정하지 않았다.

생성 이미지의 튜토리얼 대화창 크기와 버튼 위치는 다소 다르다. 구현에서는 하나의 공통 대화창으로 통일한다.
3단계의 강조 테두리는 7번 빈칸에 있으나 화살표 끝이 윗칸을 향한다. 구현에서 화살표를 제거하고 7번 강조 테두리만 쓰는 것을 기준으로 한다.
1단계에 보이는 목표 칩은 데모 예시이며 첫 실행 실제 목표가 아니다.
이미지 시안이며 동작 구현·기기 검증은 하지 않았다.
