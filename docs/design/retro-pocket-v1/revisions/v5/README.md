# v5 · 필터 복원 / 새싹이 일관성 / 장식 제거

[홈](screens/01-home.png) · [목표 설정](screens/02-settings.png)

- 전체·친구·모양·사물 필터의 외곽 테두리와 개별 박스 테두리를 제거했다. 선택한 ‘전체’의 채움 배경과 얇은 텍스트 사이 구분선만 유지한다.
- 설정 우측 상단의 4×3 점 장식을 제거했다. 스피커 구멍 모티프였으며 기능이 없고 메뉴 버튼으로 오인될 수 있었다.
- 새싹이는 설정의 둥근 몸, 짧은 줄기, 양옆으로 펼친 잎, 웃는 입, 작은 반짝임을 기준으로 홈에 맞췄다. 기존 홈의 각진 몸·발·다른 표정은 폐기한다.
- 홈 제목 옆 꽃 브랜드 아이콘은 유지한다. 기본 스티커 라벨도 유지한다.

## 스티커 원본 원칙

설정 미리보기·선택 목록·홈 기본 스티커 표시·붙인 칸·튜토리얼에서 **동일한 원본 자산 하나**를 재사용한다.
크기만 조정한다. 스티커마다 눈·입·잎·몸통·장식 픽셀을 다시 생성하거나 그리지 않는다.
얼굴 내부는 투명으로 처리하고 LCD 바탕을 드러낸다. 별도 피부색 금지.
이 변경은 기본 스티커 변경에 따른 기존 기록 일괄 변경 기능을 의미하지 않는다.

## 확인과 제한

필터 테두리와 우측 점 장식 제거, 홈 캐릭터 실루엣·표정 수정을 육안 확인했다.
화면별 생성 이미지이므로 스티커의 개별 픽셀까지 동일하다고 보장하지 않는다. 실제 자산 추출·공통 컴포넌트 적용은 아직 하지 않았다.
향후 구현 시 하나의 고정된 픽셀 원본을 사용해야 한다. 배경색은 v4의 고정 토큰 규칙을 유지한다.
이번 범위는 홈·설정 이미지다. 다른 기존 시안의 스티커는 아직 수정하지 않았다.

내장 image_gen 편집 도구 사용. 각 단계 프롬프트는 prompts에 저장했다. 앱 코드는 변경하지 않았다.
