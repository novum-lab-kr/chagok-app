# v4 · 픽셀 프레임과 색상 보존

[홈](screens/01-home.png) · [목표 설정](screens/02-settings.png)

## 이번 변경

- 튜토리얼 대화창처럼 프레임과 버튼 모서리를 계단형 픽셀로 변경.
- 앱 글씨 전체의 비트맵 스타일 유지 및 강조. 휴대폰 OS 상태바는 기본 글씨.
- 홈의 ‘기본 스티커’ 라벨 복원. 기능을 설명하는 짧은 라벨이며 장황한 사용법 문구와 구분한다.
- 일반 화면에 사용법 문구를 다시 넣지 않는다. 첫 실행 튜토리얼은 v3 기준 유지.

## 사용자 피드백에 따른 색상 고정

초기 v4 생성에서 얼굴 내부가 아이보리색으로 채워지고 배경 민트가 더 밝아지는 문제가 있었다.
해당 중간 결과는 최종안으로 채택하지 않았다. v3 원본을 다시 참조해 테두리 중심으로 편집했다.

- 본체 #C6DDD0, LCD #D9E3AF, 잉크 #283D32, 버튼 #EB926C, 보조 버튼 #F4F1DE 기준 유지.
- 픽셀 캐릭터는 LCD 위에 짙은 잉크 한 색으로 표현한다.
- 얼굴·몸 내부는 투명하게 하여 놓인 면의 LCD 색을 그대로 보여준다. 별도 피부색, 흰색, 아이보리 채움 금지.
- 프레임 수정이 스티커 형태·표정·색상 변경으로 이어지지 않게 한다.
- 실제 구현은 고정 토큰을 사용한다. 이미지 생성 결과의 미세한 색 변화는 새 색상 제안으로 간주하지 않는다.

## 검토 상태

두 화면의 얼굴 채움색 제거와 홈 라벨 복원을 육안 확인했다.
생성 이미지의 색상은 원본과 픽셀 단위로 일치하지 않는다. 배경색 변경을 승인받은 것이 아니며 v3 및 위 토큰이 기준이다.
화면 바깥 모서리의 계단 효과는 생성 이미지 표현일 뿐, 실제 OS 화면 모서리나 카메라 영역을 변경하는 설계가 아니다.
이번 수정 이미지 범위는 홈·설정이며 다른 화면은 아직 이 프레임 스타일로 재생성하지 않았다.
실제 폰트 선정·코드 구현·기기 검증은 하지 않았다.

## 생성 기록

내장 image_gen 편집 도구 사용. 홈·설정 모두 v3 해당 원본을 참조했다.
최종 프롬프트는 prompts 폴더에 저장. 기존 버전과 생성 원본 보존.
