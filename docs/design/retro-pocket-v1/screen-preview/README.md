# HTML 재현 실험 — 사용자가 거절한 작업본

> 시안의 입체감·프레임·글씨를 재현하지 못해 기준에서 제외했다. 후속 작업의 출발점으로 사용하지 않는다. 파일은 작업 기록으로만 보관한다.

[실패 작업 기록](index.html)

홈 2종, 목표 만들기, 목표 설정, 기록, 튜토리얼 3단계의 HTML 시안이다. 제품 앱과 분리되어 있으며 입력은 저장되지 않는다.

기준은 [v6 홈](../revisions/v6/screens/01-home.png)의 배치와 픽셀 프레임, [지정 원본](../revisions/v6/references/sprout-and-label-source.png)의 새싹 및 기본 스티커 영역이다. 새싹은 원본 이미지의 동일 좌표를 SVG로 참조하고 LCD 배경을 투명 처리한다. 화면별로 새로 그리지 않는다.

색상은 `../system/tokens.json`에서 생성한 `tokens.css`, 폰트는 보관된 NeoDunggeunmo 파일을 사용한다. 프레임, 버튼, 스티커는 공통 함수와 CSS를 사용한다. 토큰은 재현 수단이며 원본과 다르게 보이면 원본 대조 후 보정해야 한다.

## 확인 상태

- JavaScript 구문 및 자산 경로 확인.
- 브라우저 렌더링 확인 미완료: 자동 캡처용 Chrome 실행이 종료되었으며 Computer Use의 Chrome 접근도 허용되지 않았다.
- 따라서 원본과 시각적으로 일치하거나 전체 화면이 확정되었다고 간주하지 않는다. 특히 글씨 굵기, 표면 질감, 픽셀 프레임 치수는 실제 렌더링 대조가 남아 있다.
- validation 및 긴 텍스트/다수 목표 상태는 요청대로 후속 작업이다.
