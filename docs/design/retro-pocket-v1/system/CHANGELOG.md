사용자의 시안 재현 요청에 따라 형태만 보정. 패널/다이얼로그 계단 단위 4px, 버튼/입력 3px, 셀 2px로 분리. 패널 안쪽 프레임 시작 8px, 안쪽 선 2px, 내용 여백 18px. 중첩 프레임은 안쪽으로 갈수록 절삭 폭을 줄여 작은 홈이 반복되지 않게 수정. 버튼 상단·좌측 하이라이트, 굵은 네 모서리 선택 표시, 픽셀 UI 아이콘 추가. 새싹은 잎·팔·발이 각진 단일 24×24 원본으로 보정. 새 홈/비교 스토리 추가. 여섯 색과 폰트·글씨 크기는 변경하지 않음. 이미지와의 픽셀 단위 일치나 최종 승인 상태를 뜻하지 않음.
